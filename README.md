# CARTA — Porta do Grok

Site público, estático e só de leitura do projeto CARTA (Bruno Henry): Enciclopédia das Engrenagens (texto completo),
Manual de Tudo, mapa do código, portões e estado atual. Feito para qualquer pessoa ou IA ler, sem login nem chave.

Abra: https://espirrosaga2020-tech.github.io/carta-porta/ · para IAs: `llms.txt` / `llms-full.txt` / `carta.json`.

Gerado pelo Grok Bot a partir de `tools/porta_publica/gerar_site.py` (repositório privado), com filtro de privacidade
e varredura de segredos (gitleaks) antes de publicar. Para atualizar: gere de novo e faça um commit novo aqui.
