Nada foi apagado: cada contagem antiga continua valendo para o critério da época dela. As divergências estão também em registry/CONHECIMENTO_DIVERGENCIAS.v1.json e aparecem em /conhecimento sem reconciliação.

Regra para contar de novo

O número público vem sempre da API (/api/enciclopedia/v1/publico), nunca escrito à mão numa página. Se o critério mudar outra vez, acrescente uma linha nesta tabela — não reescreva as anteriores.
